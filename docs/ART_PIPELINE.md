# Art pipeline
- Concepts → Assets/Art/Concepts (base wheel model, final upgrade, old man + cat, scavenger).
- Model low-poly in Blender → export FBX → Assets/Art/Models. Hand-painted textures 512–1024px → Assets/Art/Textures.
- Modular character: body core (jar+brain) + part sockets (locomotion, arms) so parts swap visually.
- Environment: modular kit (walls, floors, overgrowth), flickering-light prefabs.
- Dialogue sprites: 2D, transparent PNG.
- Use URP, toon-ish/unlit-leaning shaders to keep hand-painted look.
